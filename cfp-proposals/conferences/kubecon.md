# KubeCon + CloudNativeCon

**Editions:** EU (Amsterdam, March 2026) + NA (Salt Lake City, November 2026)
**Website:** https://events.linuxfoundation.org/kubecon-cloudnativecon-europe/
**CFP window:** EU: October–December | NA: April–June
**Language:** English

## Theme

The world's largest cloud-native conference (20,000+ attendees at EU/NA editions). Organized by CNCF. Security is a prominent track covering: vulnerability management, identity/credential management, threat modeling, runtime security, supply chain (SBOM, Sigstore, in-toto), detection engineering, and confidential computing. Falco is a CNCF project — talks about Falco have direct relevance to the project's community. Co-located events include OpenSSF Day and Open Source SecurityCon (same week).

## Format

- 30-min talk slots (main conference, very competitive)
- Co-located events (full-day, day before main conference — more accessible CFP)
- ContribFests (hands-on community sessions)
- KubeCon is peer-reviewed by the program committee

## What gets accepted

- Cloud-native security research with concrete findings
- Falco, eBPF, and runtime security tooling (Falco is a CNCF project)
- Supply chain security (Sigstore, SLSA, in-toto, SBOM)
- AI/ML security in cloud-native environments
- Detection engineering and observability
- Kubernetes-specific threat research
