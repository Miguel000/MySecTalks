# FOSDEM — Security Devroom

**Location:** Brussels, Belgium (Université Libre de Bruxelles)
**Typical dates:** First weekend of February (2 days)
**Website:** https://fosdem.org/
**CFP window:** October – November (devroom CFPs open ~October)
**Language:** English

## Theme

The world's largest gathering of open-source developers and contributors (~8,000 attendees, free entry). Organized entirely by volunteers, no commercial sponsors influence content. Dozens of devrooms covering specific OSS ecosystems and topics. The **Security devroom** covers: supply chain security, SBOM, vulnerability management, cryptography, OSS security tooling, and secure development practices. Adjacent devrooms: eBPF (relevant for Falco), Containers, and Monitoring.

## Format

- 25-min and 40-min talk slots per devroom
- Lightning talks (5 min) in some devrooms
- Devroom CFPs are run independently by devroom organizers
- All talks live-streamed and recorded

## What gets accepted (Security devroom)

- OSS security tools and their development
- Supply chain security (SBOM, Sigstore, in-toto, provenance)
- Vulnerability management in OSS ecosystems
- Runtime security and monitoring (Falco, eBPF-based tools)
- Secure development practices with OSS tooling
- Applied cryptography in OSS projects

## Submission tips

- Submit to the **Security devroom** CFP specifically (separate from main FOSDEM CFP)
- Also consider the **eBPF devroom** for the Hook or Five Tiers talk (Falco uses eBPF)
- Emphasize the OSS contribution: "we're releasing these rules under Apache 2 for the community"
- 25-min slot is typical for devrooms — keep the abstract focused on one central idea
- FOSDEM audience is developers, not security specialists — frame talks for an informed but non-specialist audience
- CFP October–November — watch FOSDEM blog for devroom CFP announcements

## Notes

First-time submission target. FOSDEM is the flagship OSS conference and the Security devroom is a strong fit for the supply chain and npm worm talks.
