# BugCON

**Location:** Mexico City, Mexico
**Typical dates:** November (2 days)
**Website:** https://bugcon.org/
**CFP window:** July – September
**Language:** Spanish (English also accepted)

## Theme

Mexico's primary community security conference. Technical focus covering offensive research, malware, reverse engineering, web security, cloud, and emerging threats. Non-commercial, community-organized by Mexican security researchers. Growing international attendance. Strong CTF tradition. Audience is practitioners, students, and researchers primarily from Mexico and Central America.

## Format

- 45-min talk slots
- Workshops (day before conference)
- CTF competition

## What gets accepted

- Technical security research with hands-on takeaways
- Tool releases and OSS projects
- Malware and threat analysis
- Cloud and container security
- AI/ML security (expanding track)
- Educational content that is technically rigorous

## Submission tips

- Spanish preferred but English is accepted
- BugCON values practical, hands-on content — include a demo or workshop component if possible
- The community is younger and more student-oriented than Ekoparty/8.8 — slightly more accessible framing helps
- CFP July–September — later than most, convenient if Ekoparty/8.8 submissions are already done
- Workshop proposals welcome alongside talk submissions

## Notes

First-time submission target. BugCON is the natural complement to Ekoparty for Mexican/Central American reach. The npm worm and Five Tiers talks are the strongest fits. CFP July–September means it can be submitted after the summer EU conference season, making it a low-friction addition to the submission pipeline.
