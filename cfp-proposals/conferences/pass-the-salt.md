# Pass The Salt

**Location:** Lille, France
**Typical dates:** July (3 days)
**Website:** https://pass-the-salt.org/
**CFP window:** January – March

## Theme

Free, non-commercial conference dedicated to security and free/open source software. Every talk must be about OSS tools or OSS-based research. No vendor pitches, no commercial tools. The audience is developers, researchers, and security practitioners who build or use OSS security tools.

## Format

- 25-min and 50-min talk slots
- Workshops also accepted (half-day or full-day)
- Lightning talks on last day

## What gets accepted

- Tool releases or significant updates to OSS security tools
- Research that uses OSS tools as the primary vehicle
- Methodology talks where the techniques are reproducible with OSS
- Educational content aimed at practitioners (not academics)

| Talk | Fit | Notes |
|---|---|---|
| Five Tiers of AI Agent Threat | ✓ Strong | All rules released as OSS, Falco is the engine |
| Shai-Hulud: npm Worms | ✓ Strong | Runtime detection via OSS Falco; npm ecosystem awareness |
| Hook Before You Look | ✓ Good | OSS Rust plugin + Apache 2 rules; needs to emphasize tool release |

## Submission tips

- Lead with the OSS tool / release — committee skims for "what does the audience get to use?"
- Mention concrete rule counts, detection examples, or findings
- Workshop format is especially valued — propose one if the material suits it
- Past accepted talks: Falco contributors, OWASP tool authors, malware detection OSS projects

## Notes

Already spoken at similar French community events (EsLibre, T3chfest). Pass The Salt is the top EU venue for OSS security — submit here first for the Falco-heavy talks.
