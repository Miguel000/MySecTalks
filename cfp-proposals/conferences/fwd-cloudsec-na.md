# fwd:CloudSec North America

**Location:** Bellevue, Washington, USA (Meydenbauer Center)
**Typical dates:** June (2 days)
**Website:** https://fwdcloudsec.org/conference/north-america/
**CFP window:** February – April
**Language:** English

## Theme

Non-profit cloud security conference, practitioner-focused. Same values as the EU edition: attacking and defending cloud platforms, container and Kubernetes security, supply chain in cloud environments, runtime detection, identity and privilege escalation. No vendor pitches. Community-organized, capped at ~350 attendees.

## Format

- 40-min talk slots (two tracks)
- Capped attendance — focused, engaged audience
- Talks recorded and published

## What gets accepted

- Cloud attack and defense research with concrete findings
- Container, Kubernetes, and runtime security
- Supply chain security in cloud environments
- AI/ML threats in cloud infrastructure
- Detection and incident response for cloud platforms
