# GitHub Universe

**Location:** San Francisco, USA (Fort Mason Center)
**Typical dates:** Late October (2 days)
**Website:** https://githubuniverse.com/
**CFP window:** March – May
**Language:** English

## Theme

GitHub's annual developer conference. Covers AI-assisted development (Copilot), supply chain security, GitHub Actions, DevSecOps, open source community, and developer productivity. Security track "Secure every commit" focuses on AI-driven vulnerability detection, secrets scanning, dependency management, and securing CI/CD workflows. Audience is developers, DevSecOps engineers, and open source maintainers — not pure security researchers.

## Format

- 30-min and 45-min talk slots
- Demo-heavy sessions preferred
- Workshops and lab sessions
- "Thought leadership" and "practitioner" session tracks

## What gets accepted

- AI-assisted security tooling (GitHub Copilot security features context)
- Supply chain and dependency security research
- Securing GitHub Actions workflows (very relevant to our CI/CD talk)
- DevSecOps practices and tooling
- Open source project security
- AI agent security (growing as Copilot and AI coding agents proliferate)

## Submission tips

- Frame talks in terms of GitHub's platform: "GitHub Actions workflows," "GitHub Copilot users," "npm packages hosted on GitHub Packages"
- Demo-driven sessions preferred — show the detection working in a GitHub Actions context
- The CI/CD supply chain talk needs minimal reframing — GitHub Actions is already the subject
- Audience is developers, not security specialists — avoid jargon, focus on "what can you do today"
- CFP March–May — submit alongside fwd:CloudSec NA submissions
