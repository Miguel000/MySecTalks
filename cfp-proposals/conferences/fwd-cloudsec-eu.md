# fwd:CloudSec Europe

**Location:** London, UK (Park Plaza Victoria)
**Typical dates:** September (2 days)
**Website:** https://fwdcloudsec.org/conference/europe/
**CFP window:** May – July
**Language:** English

## Theme

Non-profit, practitioner-focused cloud security conference. Covers attacking and defending cloud platforms (AWS, GCP, Azure), cloud-native threats, container and Kubernetes security, identity and access, supply chain in cloud environments, and runtime detection. Explicitly non-vendor — talks must be research-driven with no product pitches. Community-organized. Companion to the North America edition.

## Format

- 40-min talk slots (two tracks)
- Capped at ~350 attendees (keeps it focused)
- Talks recorded and published

## What gets accepted

- Cloud attack and defense research with concrete findings
- Container, Kubernetes, and runtime security
- Supply chain security in cloud environments
- Identity, credential management, and privilege escalation in cloud
- Detection and incident response in cloud platforms
- AI/ML security with cloud infrastructure angle
