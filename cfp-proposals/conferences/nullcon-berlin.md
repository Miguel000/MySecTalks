# Nullcon Berlin

**Location:** Berlin, Germany
**Typical dates:** September (2 days conference + 3 days training)
**Website:** https://nullcon.net/berlin/
**CFP window:** April – June
**Language:** English

## Theme

Berlin edition of the Indian security conference (Nullcon Goa also runs annually). Covers offensive and defensive security, vulnerability research, malware, cloud security, AI/ML threats, and emerging attack surfaces. Growing European presence, international audience. Live bug bounty event and CTF run alongside. Research-focused, non-commercial.

## Format

- 45-min talk slots
- 3-day trainings before the conference
- Live bug bounty event
- CTF competition

## What gets accepted

- Novel security research with technical depth
- Vulnerability research with working demos
- Malware and threat analysis
- Cloud, container, and runtime security
- AI/ML security (growing track)
- Offensive and defensive research

## Submission tips

- Nullcon values technical depth and novel research — same bar as DeepSec or troopers
- Berlin audience is pan-European with significant Indian diaspora security community
- CFP April–June — same window as SEC-T and 44CON; plan for spring submission season
- Live bug bounty format means the audience values working, demonstrable research

## Notes

First-time submission target. Berlin in September creates a potential circuit with SEC-T (Stockholm, also September). The AI agent threat model and Hook tool are the strongest submissions. September timing means summer preparation time for demo polish.
