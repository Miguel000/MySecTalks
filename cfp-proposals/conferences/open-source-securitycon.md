# Open Source SecurityCon

**Location:** Co-located with KubeCon EU — Amsterdam, Netherlands (March 23, 2026)
**Typical dates:** Day before KubeCon EU main conference
**Website:** https://events.linuxfoundation.org/kubecon-cloudnativecon-europe/co-located-events/open-source-securitycon/
**CFP window:** October – November (same cycle as KubeCon EU)
**Language:** English

## Theme

CNCF + OpenSSF co-organized full-day event focused on cloud-native and open-source security. Topics: supply chain security (SLSA, Sigstore, in-toto, SBOM), secure development practices, OSS vulnerability management, AI-driven security tooling, runtime security, and community approaches to securing the OSS ecosystem. Separate registration from main KubeCon but co-located.

## Format

- 30-min talk slots (single track or two tracks)
- ~200–400 attendees (focused, highly engaged audience)
- Talks recorded and published by CNCF
- CFP managed through the Linux Foundation event system

## What gets accepted

- Supply chain security research with OSS tooling
- Runtime security and detection (Falco, eBPF-based tools directly relevant)
- AI/ML in security tooling and threat detection
- OSS project security practices and community governance
- Threat research that impacts the cloud-native and OSS ecosystem
