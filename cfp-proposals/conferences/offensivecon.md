# OffensiveCon

**Location:** Berlin, Germany
**Typical dates:** May (2 days)
**Website:** https://www.offensivecon.org/
**CFP window:** January – March
**Language:** English

## Theme

Berlin-based technical conference focused exclusively on offensive security research. Vulnerability research, exploitation techniques, reverse engineering, kernel exploits, and novel attack primitives. Very high technical bar — the audience is researchers and practitioners who build offensive tools and find vulnerabilities professionally. Non-commercial, no marketing content.

## Format

- 50-min talk slots (single track)
- No workshops
- Talks recorded and published

## What gets accepted

- Novel exploitation techniques with working PoC
- Vulnerability research with technical depth
- Reverse engineering of complex targets
- Attack primitives that advance the state of the art
- Tool releases with significant offensive capability

## Submission tips

- Reframe defensive talks from the attacker's perspective — OffensiveCon wants "here's how to attack X" not "here's how to detect X"
- The Hook talk can be framed as "5 attack techniques against AI agents that bypass all existing security tooling"
- Working PoC is expected, not optional
- CFP January–March — submit after the new year

## Notes

First-time submission target. The npm worm and Hook talks have the best fit if framed offensively. The CI/CD patterns talk can work if the focus is on the attack techniques rather than the Falco rules. OffensiveCon is a prestige venue in the offensive community.
