# OWASP Global AppSec

**Editions:** EU (Vienna, Austria) + USA (San Francisco, USA)
**Typical dates:** EU: June | USA: November
**Website:** https://owasp.org/events/
**CFP window:** EU: November–February | USA: February–May
**Language:** English

## Theme

OWASP's flagship annual conference in two editions. Covers application security, supply chain, CI/CD security, cloud-native threats, AI/ML security, and secure development. Strong developer and AppSec practitioner audience. Non-commercial research track alongside sponsored content. OWASP is the home of many OSS security projects — audiences are receptive to new OSS tools and frameworks.

## Format

- 45-min talk slots (multiple tracks)
- 2-day paid trainings before the conference
- Lightning talks
- Workshops

## What gets accepted

- Application and API security research
- Supply chain security (SBOM, dependencies, CI/CD)
- AI/ML security (fast-growing track)
- OSS security tools and frameworks
- Cloud-native and container security
- Secure development methodology and education

## Submission tips

- OWASP audience is developer-adjacent — frame talks for AppSec engineers, not just security researchers
- Connecting to OWASP Top 10 for LLMs (for AI talks) or OWASP SAMM (for CI/CD talk) adds familiarity
- EU edition (Vienna) is convenient alongside existing EU conference circuit
- CFP for EU opens November — submit alongside the RootedCon CFP window
- Both editions can receive the same abstract with minor adaptation

## Notes

First-time submission target. OWASP AppSec EU in Vienna is geographically convenient alongside DeepSec (also Vienna, November). The CI/CD and npm worm talks are the strongest fits — the AppSec audience deals with supply chain risks daily. Consider submitting to both EU and USA editions in the same year.
