# ShmooCon

**Location:** Washington D.C., USA (Washington Hilton)
**Typical dates:** January / February (3 days)
**Website:** https://shmoocon.org/
**CFP window:** August – October (for January event)
**Language:** English

## Theme

Small, community-focused US security conference with a strong culture of educational content and accessibility. Organized by the Shmoo Group, capped at ~2,000 attendees. Values talks that teach something real over talks that sell something. Three tracks: One Track Mind (main, single track), Build It (tool-focused), Belay It (security fundamentals / education). Non-commercial feel in a commercial setting.

## Format

- One Track Mind: 50-min single-track main talks (highest competition)
- Build It: 50-min tool/research talks (medium competition)
- Belay It: 50-min educational / fundamentals talks (good for methodology talks)

## What gets accepted

- Accessible technical talks that don't require deep specialist knowledge
- Tool releases with clear educational value
- Methodology talks that generalize beyond a specific CVE or tool
- Security education research
- Novel research presented in an approachable way

## Submission tips

- Belay It track is significantly less competitive than One Track Mind — submit educational talks there
- ShmooCon values clarity and accessibility; avoid jargon-heavy abstracts
- The community is smaller than DEF CON/BH but engaged and influential (many DC-area government and contractor security teams attend)
- CFP August–October — set a reminder after summer, submit the AI Challenges or Five Tiers talks

## Notes

First-time submission target. The AI-Robust Security Challenges talk is a strong Belay It submission — it is explicitly about education and methodology, which is the track's purpose. The Five Tiers talk fits Build It well. CFP is August–October, same window as C3.
